# Rights and Licensing Review

## Scope

This packet covers `SR-013`. It requests a rights and open-licensing decision for a repository containing several legally distinct layers.

This is a decision packet, not legal advice and not a licence grant.

## Asset classes

1. **Code and validation tools**
   - Python validators and tests
   - GitHub workflow files
   - utility scripts

2. **Original project documentation**
   - research synthesis
   - governance records
   - adaptation decisions
   - indexes and production frameworks

3. **Original screenplay and treatment**
   - English Fountain files
   - Tamil Fountain files
   - treatments, beat sheets and character work

4. **Third-party literary and scholarly material**
   - primary epic editions
   - translations
   - Bharathidasan’s *Manimekalai Venpa*
   - journal articles, books and archaeological reports

5. **Future visual and production assets**
   - generated storyboard frames
   - commissioned art
   - photographs and scan references
   - maps, diagrams, fonts and textures

## Decisions requested

For each asset class, determine:

- copyright owner;
- redistribution status;
- quotation limits;
- derivative-work status;
- permitted repository visibility;
- preferred licence or “all rights reserved” status;
- attribution wording;
- commercial-use permission;
- share-alike requirement, if any;
- contribution licence or assignment requirement;
- whether generated or commissioned assets need separate provenance.

## Required safeguards

- Do not apply one blanket licence until compatibility is confirmed.
- Third-party source text must remain citation-only or private unless redistribution rights are established.
- A public URL does not imply permission to copy.
- Project summaries must not substitute for licensed reproduction.
- Generated images require retained prompts, model/tool provenance and a human rights review.
- Commissioned visual work requires written ownership and reuse terms.
- No badge may imply a settled licence before the decision is recorded.

## Decision options to assess

The reviewer should assess, not automatically select:

- a permissive software licence for code;
- a Creative Commons licence for original documentation;
- a separate, more restrictive or reserved-rights status for screenplay text;
- citation-only treatment of third-party material;
- a contributor agreement or Developer Certificate of Origin;
- a machine-readable asset-rights manifest.

## Required output

1. a rights matrix for every asset class;
2. recommended licence text and exact file placement;
3. attribution and notices requirements;
4. contribution terms;
5. a list of files that cannot be redistributed;
6. rules for storyboard and production assets;
7. a release checklist.

No `LICENSE` file will be added until the owner accepts a reviewed recommendation.
