# Chapter 1 Pilot Package

This directory contains the English Chapter 1 internal review package.

## Primary review file

`Manimekalai_Chapter_1_Pilot_English_v1.0.pdf` - eight lettered pages in reading order.

## Machine-readable files

- `guided-view.json` - ordered panel/region geometry for later Kindle Create authoring;
- `asset-manifest.csv` - size, dimensions and SHA-256 for unlettered, lettered and PDF deliverables;
- `phone/` - 720-pixel-wide static QA previews;
- `tablet/` - 1200-pixel-wide static QA previews.

This is not a KPF file and has not passed Kindle Previewer/device testing.
